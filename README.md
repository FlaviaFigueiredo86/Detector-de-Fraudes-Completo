🔎 Detector de Fraudes
📌 Sobre o projeto

Este projeto foi desenvolvido para identificar possíveis tentativas de fraude ou mensagens suspeitas por meio da análise de textos.

O sistema verifica o conteúdo de uma mensagem procurando por palavras suspeitas, expressões que podem indicar fraude e erros ortográficos que podem aparecer em mensagens fraudulentas.

🎯 Objetivo

O objetivo do projeto é criar uma ferramenta simples capaz de analisar mensagens e identificar possíveis sinais de fraude, ajudando o usuário a reconhecer conteúdos que merecem atenção.

⚙️ Como funciona

O sistema recebe um texto e realiza uma análise procurando por características consideradas suspeitas.

Durante a análise, o programa verifica:

🔤 Erros ortográficos;
⚠️ Palavras suspeitas;
🚨 Expressões relacionadas a possíveis golpes;
📝 Características presentes no texto.

Depois da análise, o sistema apresenta um resultado indicando se a mensagem possui possíveis sinais de fraude.

💡 Exemplo

Uma mensagem contendo palavras suspeitas ou vários erros de escrita pode receber um alerta, indicando que o conteúdo deve ser analisado com cuidado.

Exemplo:

"Parabens voce foi selecionado para receber um premio! Clique agora e informe seus dados."

O sistema pode identificar características suspeitas nessa mensagem e gerar um alerta.

🚀 Possíveis melhorias

Este projeto possui finalidade educacional. A identificação de palavras suspeitas ou erros ortográficos não significa, por si só, que uma mensagem seja fraudulenta. O sistema serve como uma ferramenta de análise e alerta.

Projeto desenvolvido para fins de aprendizado em programação.
